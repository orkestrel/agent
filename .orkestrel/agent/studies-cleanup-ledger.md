# Studies cleanup ledger

Durable record of the cleanup that moved Agent's study proofs of Study-owned mechanisms into Study. Agent keeps the consumer wiring; every claim a removed Agent test carried is either proved by a named Study test that turns red under a named mutation, or folded into a kept Agent test. Repositories: Agent `tests/**` paths are relative to this repository; Study paths (`tests/src/**`, `src/**`) are relative to `../study`. Every Agent path is where the test stands after U4 (memory layout one file per module) and U6 (endurance and grading moves). A mutation is a transient edit of Study `src`, reverted after the run.

Provenance: Agent `a96fe45` (U3 drops and folds), `8641370` (U5 trims), `c7973ae` (U4 layout), Study `a1dea1a`, and the U6 repair of the falsify findings. The checked, machine-readable form of each unit lives in the ignored `tmp/units/studies-cleanup*-ledger.json`; this file is the durable summary.
