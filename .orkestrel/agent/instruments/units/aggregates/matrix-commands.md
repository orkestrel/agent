```powershell
function Invoke-MatrixCommand {
    param([string]$Name, [int]$Cap, [string[]]$Arguments, [int[]]$Allowed = @(0, 3))

}
```

Plan and execute A, then B, then C. This explicit loop attempts every planned cell in order, retains nonzero runs for invalidity reporting, and avoids stopping the entire population after one refused cell. Root examines a nonzero run before proceeding; an operationally interrupted run is not overwritten. Each run gets a distinct cold-start wrapper and journal.

```powershell
foreach ($Stage in @('A', 'B', 'C')) {
    $Plan = "$MatrixRoot/plans/$Stage.json"
    Invoke-MatrixCommand "plan-$Stage" 240 @("$Harness/.build/bench5/matrix.js", 'plan', '--root', $MatrixRoot, '--stage', $Stage, '--out', $Plan) @(0)
    $Entries = Get-Content -Raw -LiteralPath $Plan | ConvertFrom-Json
    foreach ($Entry in $Entries) {
        [string[]]$Payload = @("$Harness/.build/tools/run-one.js", $Entry.name, 'bench5', "$MatrixRoot/runs", '--') + @($Entry.args)
        Invoke-MatrixCommand $Entry.name 14400 $Payload @(0, 1, 3)
    }
}
```

Build the final report, including preparation attempts that no feasible evaluated cell referenced. The input construction that follows includes generation costs explicitly only when no accepted referenced fit already supplies them; repeated references and fit-diagnosis aliases of the same verified generation are deduplicated into one cost row. Distinct generation manifests remain separate even when their measured totals match.

```powershell
[string[]]$Evidence = @()
foreach ($Key in $Models.Keys) {
    $HasEvaluatedFit = $false
    foreach ($Bit in @(0, 1)) {
        $Base = "$MatrixRoot/$Key-think$Bit"
        foreach ($Phase in @('resource', 'full', 'pilot')) {
            $Manifest = "$Base/$Phase/manifest.json"
            if (Test-Path -LiteralPath $Manifest) { $Evidence += @('--preparation', $Manifest) }
        }
        foreach ($Stage in @('A', 'B', 'C')) {
            $Entries = Get-Content -Raw -LiteralPath "$MatrixRoot/plans/$Stage.json" | ConvertFrom-Json
            foreach ($Entry in $Entries) {
                if ($Entry.name -match "^l6-$Key-think$Bit-aggregate-" -and (Test-Path -LiteralPath "$MatrixRoot/runs/$($Entry.name)/run.json")) { $HasEvaluatedFit = $true }
            }
        }
    }
    $Calibration = "$MatrixRoot/calibration/$Key"
    if (-not $HasEvaluatedFit -and (Test-Path -LiteralPath "$Calibration/generation/manifest.json")) { $Evidence += @('--preparation', "$Calibration/generation/manifest.json") }
    foreach ($Phase in @('corpus', 'generation', 'fit')) {
        if (Test-Path -LiteralPath "$Calibration/$Phase/diagnosis.json") { $Evidence += @('--preparation', "$Calibration/$Phase/diagnosis.json") }
    }
}
if (Test-Path -LiteralPath "$MatrixRoot/shadows") {
    foreach ($File in Get-ChildItem -LiteralPath "$MatrixRoot/shadows" -File -Filter '*.json') { $Evidence += @('--shadow', $File.FullName) }
}
Invoke-MatrixCommand 'comparison' 240 (@("$Harness/.build/bench5/compare.js", 'report', '--base', "$MatrixRoot/runs", '--out', "$MatrixRoot/comparison.json", '--packet', "$MatrixRoot/audit/packet.json", '--keys', "$MatrixRoot/private/keys.json", '--labels', "$MatrixRoot/audit/labels.json") + $Plans + $Evidence) @(0)
```
