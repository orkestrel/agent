# Aggregate feasibility custody

The existing contract binds resource evidence to one exact frozen configuration. A successor that changes a canonical matrix source or scenario must be frozen again, and its prior resource manifest cannot be supplied as evidence for that new freeze: `readFrozen` compares the frozen file list against the current matrix source population and rejects stale input; `readResource` requires its embedded frozen reference to be deeply equal to the caller's reference and checks each attempt's phase, arm, copy, budget ladder, and terminal decision ([source population](.orkestrel/agent/instruments/harness/bench5/matrix/helpers.ts:87), [freeze validation](.orkestrel/agent/instruments/harness/bench5/matrix/helpers.ts:132), [resource validation](.orkestrel/agent/instruments/harness/bench5/matrix/helpers.ts:173)). Frozen custody also verifies the settings, seed, census, tags, and role model digests against their frozen hashes and protocol expectations ([frozen role checks](.orkestrel/agent/instruments/harness/bench5/matrix/helpers.ts:136)). The tracked population explicitly includes build manifest, matrix sources, harness runner/series, vendored clients, long scenario, and variants v1-v8 ([tracked file list](.orkestrel/agent/instruments/harness/bench5/matrix/helpers.ts:90)).

The allowed order for a changed canonical configuration is freeze the successor, run a new records resource preflight against that freeze, then run full preflight with that exact freeze and the accepted resource manifest. The CLI requires `--out`; model phases require `--live`; resource requires `--frozen`, while full additionally requires `--resource` ([phase entry](.orkestrel/agent/instruments/harness/bench5/matrix/Matrix.ts:54)). Resource attempts are records/copy 1 tied to the frozen reference ([resource attempt creation](.orkestrel/agent/instruments/harness/bench5/matrix/Matrix.ts:220)). Full preflight reads the accepted resource under the same frozen reference, requires its complete records trace, derives a bound from that trace, and records both references in the full execution ([full preflight](.orkestrel/agent/instruments/harness/bench5/matrix/Matrix.ts:326)). Evaluation validation then requires an accepted resource with matching reserve; full evaluation additionally requires an accepted full manifest with identical frozen reference and budget and a single accepted attempt whose execution uses the same resource ([execution resource check](.orkestrel/agent/instruments/harness/bench5/matrix/helpers.ts:237), [full evaluation check](.orkestrel/agent/instruments/harness/bench5/matrix/helpers.ts:320)). A matrix plan reads the frozen and resource manifests from the configuration directory, excludes infeasible resource decisions, and only attaches an accepted full manifest to a full evaluation ([plan resource read](.orkestrel/agent/instruments/harness/bench5/matrix/Matrix.ts:428), [plan full binding](.orkestrel/agent/instruments/harness/bench5/matrix/Matrix.ts:485)).

These inspected contracts provide no equivalence-based reuse path for similar or identical decision requests across distinct freezes: accepted phase evidence is referenced and compared by frozen/resource manifest identity and content hashes. The separately named `readSeedCache` path copies exact seed bytes from a checked freeze into a configuration-scoped judge cache; it is not reuse of resource or full feasibility evidence ([seed-cache reader](.orkestrel/agent/instruments/harness/bench5/matrix/helpers.ts:503), [plan cache write](.orkestrel/agent/instruments/harness/bench5/matrix/Matrix.ts:513)).

For the inspected q2-think0 example, the freeze manifest hashes to `026ae06de9f2d132d93b20f5077ce17f77898c241bc94a4fa071f6579166d172` and binds 75 files, q2 with thinking disabled, the settings and seed references, and the role digests. Its resource manifest hashes to `b7b098fd96e3a7d4058685f3d8f5a7491dfd257e3ca9c8fd1122a43be9689686`, is accepted at reserve 512/window 3072/predict 0, and carries the exact freeze hash. Its adjacent full manifest hashes to `eb56191859179bf3bfaf2204fad9ec073a632b112dc105577436dc4a2d4ff3d4`, is not accepted, and records `request 20: transport`; therefore this evidence set has accepted resource custody but no accepted full-view custody ([q2 freeze evidence](.orkestrel/agent/instruments/results/l7/q2-think0/freeze/manifest.json:1), [q2 resource evidence](.orkestrel/agent/instruments/results/l7/q2-think0/resource/manifest.json:1), [q2 full evidence](.orkestrel/agent/instruments/results/l7/q2-think0/full/manifest.json:1)).

This conclusion is bounded to the inspected l6 matrix readers, planning path, and q2 manifests. It does not claim semantic similarity of request bodies or any reuse contract outside those paths.
