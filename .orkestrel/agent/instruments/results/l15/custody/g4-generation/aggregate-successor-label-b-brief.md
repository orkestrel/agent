## Execution

Perform the assignment yourself and spawn nothing. Read every complete candidate in context and split material propositions, preserving entity, attribution, time, conditions, negation, and completion. A request to act does not prove completion. Superseded values cannot become current. Resolve aliases only from supplied sources, without world knowledge or preference for useful-sounding wording.

Use supported when every material assertion is entailed, contradicted for definite conflict, unsupported for definite added assertion, and ambiguous for materially unresolved meaning/evidence. Supported requires every proposition supported. Explain mixed cases and choose the substantive nonpositive label; root adjudicates uncertainty. Paraphrase alone is not a factual defect.

Preserve every occurrence ID. Exact semantic duplicates may share analysis only after candidate, question, state, and sources equality is established. Component/revision/occurrence identities remain in output. Compute item hashes as SHA256(JSON.stringify(parsedItem)) in original parsed property order. Read complete evidence without truncation.

## Output

Write a JSON array with each entry {id:string,item:string,verdict:'supported'|'unsupported'|'contradicted'|'ambiguous',propositions:[{text:string,verdict:the same union,evidence:string[]}]}. Each candidate needs nonempty propositions. Evidence strings are bare exact contiguous source quotations with no prefixes, ellipses, or commentary. Explain identities, missing entailment, or conflict in proposition.text or report. For unsupported additions, quote the relevant actual source and describe its limitation; never invent a quotation describing absence.

Report input/output hashes, census, verdict counts, exact duplicate-group method, and ambiguities. No numeric judge score. Root owns adjudication, wrapper, and acceptance. Report readiness before packet release, then progress while labeling, and completion only after labels and checks close.

## Deviation contract

Stop for an incomplete packet or contradictory structural fields with expected/found/evidence/done and one hypothesis. Settle presentation in scope. Label semantic uncertainty ambiguous without seeking private data.
